研究目标

围绕“RAG 检索增强生成”建立一份可执行的学习报告，帮助后续 Web Agent 生成公开页面或内部学习页面。报告重点不是罗列概念，而是把学习对象拆成目标、结构、实践路径、风险边界和下一步行动。

核心概念

    实践路径

    1. 先注册长期 Agent，并写明 Profile。
    2. 为真实反复出现的协作声明 Collaboration。
    3. 用 Message 替代 Human 手动转述。
    4. 跨 Agent、多 Turn 或多天的工作使用 Topic。
    5. 正式结果保存 Artifact。
    6. 缺少人的判断时创建 Needs You。

    风险边界

    • Profile 不是授权证明。
    • Message 完成不代表业务正确。
    • Topic resolved 不代表现实动作全部完成。
    • GitHub Pages 发布成功只证明页面分支已推送，不证明访问链路已经刷新。
    • 如果外发或公开内容涉及承诺，应由 Human 明确授权。

    Agent Team 工作流

    1Human 提供课题
    2Research Agent 生成报告 Artifact
    3Web Agent 写入页面代码
    4Git 推送 main 与 gh-pages
